# Aplicación Web Modularizada

## ¿Qué es modularización?
Es dividir la aplicación en partes reutilizables como header, footer y sidebar.

## Fragmentos
Se cargan con fetch desde archivos HTML externos.

## Plantillas
Se usa <template> para renderizar productos dinámicamente.

## Web Components
Se creó un componente personalizado con Shadow DOM.

## Login
Se implementó con validación básica en JS (no seguro en producción).

## Buenas prácticas
- Separación de archivos
- Nombres claros
- Código organizado
